Universal integration model

SMS is the front door. Orivo is the secure system behind it.

The winning model is not to put the whole healthcare workflow inside text messages. The model is to let members start with SMS or voice, then use payer, pharmacy, provider, and benefit data behind the scenes to route the safest next step.

SMS model

SMS-first does not mean SMS-only.

SMS should be the access channel, not the full record, not the chart viewer, and not the main place where care teams exchange detailed health information. The secure backend is where records, identity, permissions, audit logs, and partner data live.

📱
SMS channel
Use for intake, safe summaries, reminders, identity prompts, and secure-link handoff when detail is needed.
🔐
Secure Orivo core
Use for storage, data contracts, consent state, audit trails, partner feeds, and decision support logic.
👩‍⚕️
Care-team side
Use authenticated portals, verified calls, SSO/MFA, existing systems, or secure task queues for clinical action.

Integration fabric

AI can help ingest many APIs, but it cannot trust them blindly.

The safer claim is not “Orivo ingests any API.” The stronger claim is “Orivo uses an AI-assisted connector factory with human-approved data contracts, field mapping, validation rules, and audit trails.”

🔌
Connector layer
FHIR, flat files, SFTP, REST APIs, webhooks, X12 extracts, CSV rosters, benefit tables.
🧬
Canonical model
Normalize member, plan, benefit, medication, barrier, task, care team, consent.
🛡️
Governance layer
PHI classification, access rules, retention, consent, audit events, outbound channel policy.
🤖
AI assist layer
Read API docs, propose mappings, generate tests, detect schema drift, flag missing fields.

Hard boundary

Patients: SMS or voice for access. No patient portal required for basic help.
Care teams: secure portal, verified call, SSO, or existing system for detailed workflows.
AI: proposes, translates, summarizes, and routes. Humans approve production mappings and clinical action.

Make integration feel like a ladder, not a cliff.

Start with the lowest data level that creates measurable value. Then move up the unlock ladder as trust, data quality, and contracting mature.
