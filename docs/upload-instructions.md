# Upload Instructions

These notes are retained for historical context. Prefer normal Git commits when possible.

## Browser Upload

1. Open the GitHub repository: `https://github.com/Rando2020/github.io`.
2. Click `Add file > Upload files`.
3. Drag files into the repo root or the appropriate folder.
4. Commit the upload.
5. Visit the affected page on `https://orivohealth.com/`.

## Current Safety Notes

- Do not change DNS for routine content updates.
- Do not edit `CNAME` unless the domain changes.
- Do not collect PHI on GitHub Pages.
- Do not upload generated zip contents blindly; review changed files first.
- Prefer keeping public HTML page URLs stable until redirects are planned.
