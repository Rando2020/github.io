# Orivo GitHub Upload Instructions

## Fastest browser upload
1. Download and unzip `orivo_github_pages_updated_full.zip`.
2. Open your GitHub repo: `https://github.com/Rando2020/github.io`.
3. Click **Add file > Upload files**.
4. Drag the contents of the unzipped folder into the repo root. Do not drag the folder itself.
5. Commit with: `Update Orivo site demo links and walkthrough`.
6. Visit `https://orivohealth.com/patient-provider-demo.html`.
